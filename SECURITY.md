# Security

Report a vulnerability in the Facet plugin or the Facet MCP server privately: open **Security > Report a vulnerability** on this repository. Don't open a public issue.

We answer within two working days and credit reporters who want it.

This repository holds only manifests and one Skill; it has no code that runs on your machine. The plugin connects your agent to `https://facet.halfspacelabs.com/mcp`, which signs you in with OAuth and acts only as you, under your workspace's policy.
